# Local 3D Models

Place the Mixamo character here as:

```text
girl_dancing_04.glb
```

The loader also supports a generic replacement file:

```text
mixamo-character.glb
```

The 3D test page scales the loaded model to the scene, places it on the floor, and plays a dance animation if one exists. If no supported file is present, the page shows a simple placeholder character instead.
